# 루이스 구조식 (전자점식) 기본 규칙

원자가전자(최외각 전자)를 점(·)으로 표시. 공유결합 = 원자 사이 점 2개(전자쌍), 비공유 전자쌍(lone pair) = 한 원자 위에 점 2개.

## 그리는 순서 (이온일 때 특히 중요)

1. **전체 전자 개수 구하기**: 각 원자의 원래 원자가전자 합 → **이온이면 위첨자 전하만큼 더하거나 뺌**
   - 음이온(⁻): 전자 개수를 **더함** (전자를 얻은 상태)
   - 양이온(⁺): 전자 개수를 **뺌** (전자를 잃은 상태)
2. 원자들을 결합선(공유 전자쌍)으로 연결
3. 남은 전자를 lone pair로 배치해서 각 원자가 옥텟(8개, H는 2개) 채우도록 함
4. 검산: 형식전하 = 원래가진전자 − lone pair전자 − 결합전자의 절반

## 예시 1: NH₃ (중성 분자, 전하 조정 불필요)

```
        H
        |
   H — N :
        |
        H
```
- N-H 결합 3개, N에 lone pair 1개 남음 → N 주위 8개(옥텟) 완성

## 예시 2: NH₄⁺ (배위결합)

```
        H
        |
   H — N — H⁺
        |
        H
```
- NH₃의 lone pair가 그대로 H⁺(전자 0개)에게 넘어가 새 결합이 됨
- N-H 결합 4개, lone pair 없음
- 형식전하: N = 5(원래) − 0(lone pair) − 4(결합전자 8개의 절반) = **+1**

## 예시 3: O₂²⁻ (과산화 이온)

```
[ :Ö—Ö: ]²⁻
```
각 O: lone pair 3쌍(6개) + 결합선 1개(공유 2개) = 옥텟 8개
(상세 계산 과정은 → O2²⁻ 질의응답 노트 참고)

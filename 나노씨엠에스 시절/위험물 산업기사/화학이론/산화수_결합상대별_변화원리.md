# 결합 상대에 따라 산화수가 뒤집히는 원리

## 핵심 한 문장

같은 원소라도 **"누구랑 결합했느냐"에 따라 전하가 정반대로 바뀐다.**

## 공통 패턴 (Cl, N 둘 다 동일)

| | 금속과 결합할 때 (이온결합) | 산소와 결합할 때 (공유결합, 산소산 이온) |
|---|---|---|
| **Cl** | Cl⁻ (-1, 전자 받음) | ClO₃⁻ 안의 Cl = **+5** (전자 뺏김) |
| **N** | N³⁻ (-3, 전자 받음) | NO₃⁻ 안의 N = **+5** (전자 뺏김) |
| **H** | H⁻ (-1, 금속과 결합 시) | H⁺ (+1, 비금속과 결합 시) |

## 예시로 확인

**질화물 (N이 금속과 결합)**
```
Li3N (질화리튬): Li⁺ 3개 + N³⁻ 1개
Mg3N2 (질화마그네슘): Mg²⁺ 3개 + N³⁻ 2개
```

**질산 이온 (N이 산소와 결합)**
```
전체 이온 전하 = N의 산화수 + O 3개의 산화수 합
       -1     =    N     +  (-2 × 3)
       N = -1 - (-6) = +5
```

## 왜 이렇게 되나 — 딱 하나의 이유

**산소(O)가 전기음성도(전자를 끌어당기는 힘)가 매우 세기 때문.** 어떤 비금속(Cl, N, S, P 등)이든 산소와 결합하면, 원래 음이온이던 원소도 오히려 산소한테 전자를 뺏기는 입장이 되어 **+로 뒤집힘.**

## 계산법 (항상 동일한 공식)

```
이온 전체 전하 = 중심원소 산화수 + (O 산화수 × O 개수)
```
O는 항상 **-2로 고정** → 이걸로 중심원소 산화수를 역산.

## 정리 규칙

> "이 원소가 혼자/금속이랑 있을 때의 전하"와 "산소랑 뭉쳐서 이온이 됐을 때의 전하"는 **완전히 다른 별개의 숫자**다. 산소랑 결합했다면 무조건 새로 계산해야 한다.

## 위험물 표 적용 예

| 이온 | 중심원소 | 결합 상대 | 산화수 |
|---|---|---|---|
| ClO₃⁻ | Cl | O | +5 |
| NO₃⁻ | N | O | +5 |
| MnO₄⁻ | Mn | O | +7 |
| Cr₂O₇²⁻ | Cr | O | +6 |
| N³⁻ (질화물) | N | 금속 | -3 |
| Cl⁻ (염화물) | Cl | 금속 | -1 |

# 화학식 첨자 3종류 구분

| 위치 | 이름 | 뜻 | 예 |
|---|---|---|---|
| 앞 (보통크기) | 계수(coefficient) | 반응식에서 몇 개 참여하는지 | `2H₂O`의 앞 2 |
| 아래 | 아래첨자(subscript) | 그 원소가 몇 개 있는지 | `H₂O`의 2, `ClO₃`의 3 |
| 위 | 위첨자(superscript) | 전하가 얼마인지 (이온일 때만) | `ClO₃⁻`의 -1 |

## 아래첨자 (원자 개수)

```
H₂O   → 수소 2개 + 산소 1개
ClO₃  → 염소 1개 + 산소 3개
Na₂O₂ → 나트륨 2개 + 산소 2개
```

## 위첨자 (전하, 이온일 때만 존재)

```
Na⁺     → +1
Mg²⁺    → +2
ClO₃⁻   → 전체 이온 -1
Cr₂O₇²⁻ → 전체 이온 -2
```
중성 분자(H₂O, CO₂ 등)는 전하가 없어서 위첨자 자체가 없음.

## 계수 (반응식 전용)

```
2K + 2H₂O → 2KOH + H₂↑
```
앞의 "2"들은 원자 개수가 아니라 **분자/이온 전체가 몇 개 반응·생성되는지**를 뜻함.

## 한 줄에 모아보면

```
   2   Na⁺    ClO₃⁻
   ↑    ↑       ↑
 계수  전하+1   아래첨자3=산소3개, 위첨자-1=전체전하
```

## 핵심

**[ ]²⁻ 같은 괄호+위첨자 표기 = "전체 전자 개수를 이 전하만큼 조정하라"는 지시**
루이스 구조를 그릴 때는 반드시 이 위첨자부터 전자 개수 계산에 반영하고 시작해야 함 (→ 루이스 구조식 노트 참고).

# 전기음성도 (Electronegativity)

## 정의

원자가 공유결합 안에서 전자를 얼마나 세게 끌어당기는지 나타내는 수치. 폴링 척도 기준 0~4 사이 숫자.

## 주기율표에서의 경향

```
                  전기음성도 ↑
              →→→→→→→→→→→
    Li  Be  B   C   N   O   F
   1.0 1.5 2.0 2.5 3.0 3.5 4.0
```

- **같은 주기(가로)**: 오른쪽으로 갈수록 ↑ (핵의 양성자가 많아져서 전자를 세게 당김)
- **같은 족(세로)**: 아래로 갈수록 ↓ (전자껍질이 많아져서 핵이 멀어짐 → 당기는 힘 약해짐)

전체 원소 중 1등은 **F(플루오린), 4.0**. 그다음 O(산소, 3.5), N(질소, 3.0), Cl(염소, 3.0) 순.

## 산화수 계산과의 관계

공유결합에서 **전기음성도가 큰 쪽이 전자를 더 세게 끌어당겨서 그쪽이 "-", 상대는 "+"로 계산**됨 (실제로 전자를 완전히 뺏는 게 아니라 형식적인 회계 방식).

```
N-O 결합: O(3.5) > N(3.0) → O가 더 세게 당김 → O는 -, N은 +
```

그래서 NO3⁻ 안에서 N이 원래 -3가 음이온이어야 할 것 같지만, **산소가 전기음성도가 더 세서** N이 오히려 전자를 뺏기는 쪽(+5)이 됨.

## 금속 vs 비금속도 전기음성도로 설명됨

- **금속**: 전기음성도 낮음 → 전자를 잘 안 당김 → 잘 내줌 → 양이온
- **비금속**: 전기음성도 높음 → 전자를 세게 당김 → 잘 받음 → 음이온
- 이온결합 = 전기음성도 차이가 아주 큰 두 원소 사이에서 일어나는 결합

## 정리 한 줄

전기음성도는 "왜 이 원소가 이렇게 +/-를 가지는지"를 설명하는 가장 근본적인 숫자 — 결합상대별 산화수 변화(F가 산소산 계열이 없는 이유 포함)의 근본 원인.

**0. 1~6류 위험물 지정수량표**

   **1. 공통 성질/저장·취급 기준**

```
- 각 유별 공통 성질 (지금까지 함, 완료)
- 혼재 가능/금지 기준 (몇 류끼리 같이 저장/운반 가능한지 — 아직 안 함)
- 저장소 종류 (옥내/옥외저장소, 지하탱크, 이동탱크 등)
```

**2. 소화설비·화재 관련**

```
- 소화기 종류별 적응성 (분말/포/CO2/할로겐화합물이 어떤 유별에 맞는지)
- 화재 분류 (A,B,C,D급)
```

**3. 위험물시설 안전관리 (법규 파트)**

```
- 제조소등 설치허가 절차
- 정기점검/정기검사 대상
- 안전관리자 선임 기준
- 예방규정 대상 시설
```

**4. 계산 문제 (실기에서 특히 중요)**

```
- 지정수량 배수 계산 (여러 위험물 섞여있을 때)
- 소화기 능력단위 계산
```

**5. 화학 기초 (오늘 계속 다룬 부분, 심화는 거의 끝)**

```
- 오늘 하루로 사실상 커버됨 (산화수, 결합, 명명법, 반응식 패턴)
```

### 혼재 기준 = 서로 다른 유별의 위험물을 같은 차량/용기에 함께 실어도 되는지를 정한 규칙

2류   X    -    X    O    O    X

5류   X    O    X    O    -    X
6류   O    X    X    X    X    -
**암기법: "423 524 61"**
4류는 2,3류와 혼재 가능
5류는 2,4류와 혼재 가능
6류는 1류와 혼재 가능

**왜 이 조합들이 허용되는지 (지금까지 배운 성질로 설명됨)**

| 조합          | 이유                                                          |
| ----------- | ----------------------------------------------------------- |
| **1류 ↔ 6류** | 둘 다 "산화성"(고체/액체 차이일 뿐, 같은 성질끼리라 상대적으로 덜 충돌)                 |
| **2류 ↔ 4류** | 둘 다 가연성(고체/액체), 서로 불을 더 키우진 않음                              |
| **2류 ↔ 5류** | 가연성고체 + 자기반응성물질, 상대적으로 안정 조합                                |
| **3류 ↔ 4류** | 자연발화성물질 + 인화성액체, 지정수량 조건 하에 허용                              |
| **4류 ↔ 5류** | 인화성액체 + 자기반응성물질 (5류 다이너마이트류가 4류 용제 쓰는 경우 많아서 실무상 자주 같이 다뤄짐) |
*혼재 불가 = 절대 같은 공간 금지"가 아니라 "지정수량의 1/10 이하면 예외*

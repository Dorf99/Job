# 화학 명명법 - 두 가지 접두어 체계

이름에 붙는 접두어는 **완전히 다른 두 가지 축**이 있음. 헷갈리지 않게 구분.

---

## 축① 산화수 접두어 (차아-아-기본-과)

**기준: 중심원소의 산화수(산소 개수에 따라 변함)**

| 접두어 | 산화수 | 예시(Cl 기준) |
|---|---|---|
| 차아- | +1 | 차아염소산 (HClO / ClO⁻) |
| 아- | +3 | 아염소산 (ClO2⁻) |
| (기본형, 접두어 없음) | +5 | **염소산 (ClO3⁻)** |
| 과- | +7 | 과염소산 (ClO4⁻) |

**예시: 염소산(ClO3⁻) 계열 전체**

```
차아염소산  ClO⁻   (+1)
아염소산    ClO2⁻  (+3)
염소산      ClO3⁻  (+5)  ← 기본형
과염소산    ClO4⁻  (+7)
```

산소 개수가 하나씩 늘 때마다 산화수가 바뀌고, 그에 맞춰 접두어도 바뀜. 이 패턴은 같은 17족인 브로민(Br), 아이오딘(I)에도 그대로 적용됨 (브로민산 BrO3⁻, 아이오딘산 IO3⁻).

**적용 범위**: 중심원소 산화수가 여러 단계로 변할 수 있는 산소산 계열 (Cl, Br, I, N 등)

---

## 축② 원소 개수 접두어 (그리스어 숫자)

**기준: 이온/분자 안에 그 원소가 몇 개 들어있는가 (산화수와 무관)**

| 접두어 | 뜻 | 예시 |
|---|---|---|
| 모노(mono-) | 1 | (보통 생략) |
| **다이(di-)** | **2** | **다이크로뮴산, 이산화탄소(CO2)** |
| 트라이(tri-) | 3 | 삼산화황 |
| 테트라(tetra-) | 4 | 사염화탄소 |

**예시: 다이크로뮴산염류(Cr2O7²⁻) 이름 풀이**

```
다이(Cr 2개) + 크로뮴 + 산염류
→ 크로뮴(Cr) 원자가 2개 들어있는 산소산 이온
```

**비교**

| 이온 | 이름 | Cr 개수 |
|---|---|---|
| CrO4²⁻ | 크로뮴산 이온 | 1개 |
| **Cr2O7²⁻** | **다이크로뮴산 이온** | **2개** |

**왜 2개짜리가 존재하나**: 크로뮴산 이온(CrO4²⁻) 2개가 산소 하나를 공유하며 서로 합쳐진 구조.
```
2 CrO4²⁻ (크로뮴산 이온 2개) → Cr2O7²⁻ (다이크로뮴산 이온, 산소 하나 잃으며 결합)
```

**적용 범위**: 여러 중심원자가 산소를 공유하며 뭉친 축합 이온 (Cr2O7²⁻가 위험물 표의 대표 사례)

---

## 두 축 비교 정리

| | 축① 산화수 접두어 | 축② 원소개수 접두어 |
|---|---|---|
| 기준 | 산화수(전하 계산 결과) | 단순히 원자 몇 개인지 세기 |
| 접두어 | 차아-, 아-, (기본), 과- | 모노-, 다이-, 트라이-, 테트라- |
| 대표 예 | 염소산 (ClO3⁻) | 다이크로뮴산 (Cr2O7²⁻) |
| 계산 필요 여부 | 산소 개수로 산화수 역산 필요 | 그냥 이름에 개수가 그대로 드러남 |

**핵심**: "다이-"가 붙었다고 산화수 계열(차아/아/과)의 일부가 아니라, **완전히 별개의 이유(원자 개수)로 붙은 접두어**라는 걸 헷갈리지 않는 게 중요함.

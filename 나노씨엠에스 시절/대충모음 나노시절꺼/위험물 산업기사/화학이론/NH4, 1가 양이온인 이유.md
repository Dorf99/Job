## H는 상황에 따라 +1도 되고 -1도 됨

|상대|수소의 행동|산화수|
|---|---|---|
|비금속(O, Cl, N 등)과 결합|전자를 **내줌**|**+1** (양이온처럼)|
|금속(Li, Ca 등)과 결합|전자를 **받음**|**-1** (음이온, 하이드라이드)|

**바로 이 -1가 수소가 3류에 있는 "금속의 수소화물"

- LiH (수소화리튬): Li⁺ + H⁻
- CaH<sub>2</sub> (수소화칼슘): Ca²⁺ + 2H⁻

## Lewis 산-염기 개념

기존에 배운 산-염기(H⁺를 내놓나/받나, 아레니우스·브뢴스테드 개념)보다 더 넓은 정의. **전자쌍을 누가 주고받느냐**로 산-염기를 구분.

|구분|정의|이번 사례에서|
|---|---|---|
|**Lewis 염기**|전자쌍을 **주는** 쪽|NH<sub>3</sub> (lone pair 제공)|
|**Lewis 산**|전자쌍을 **받는** 쪽|H⁺ (빈자리 제공)|

- 배위결합 = Lewis 산-염기 반응의 결과물. "배위결합이 생겼다" = "Lewis 산-염기 반응이 일어났다"와 같은 말
- 기존 산-염기 개념(H⁺ 주고받기)의 상위 개념이라, H⁺가 아예 관여 안 하는 반응도 Lewis 산-염기로 설명 가능 (예: 금속이온 + 리간드 착물 형성)

**정리: NH<sub>4</sub>⁺가 만들어지는 과정을 한 문장으로**
> NH<sub>3</sub>(Lewis 염기, lone pair 보유)가 H⁺(Lewis 산, 빈자리)에게 전자쌍을 제공하는 **배위결합**을 통해 NH<sub>4</sub>⁺(+1 양이온)이 된다.

## 루이스 구조식 (전자점식)

원자가전자(최외각 전자)를 점(·)으로 표시. 공유결합=점 2개(전자쌍)를 두 원자 사이에, 비공유 전자쌍(lone pair)=한 원자 위에 점 2개.

**NH<sub>3</sub> (질소 최외각전자 5개, 수소 각 1개)**

```
        H
        |
   H — N :
        |
        H
```
- N-H 결합 3개 (공유 전자쌍 3개, 각각 N과 H가 전자 1개씩 냄)
- N 위의 " : " = lone pair 1개 (전자 2개, N 혼자 다 가짐)
- N 주변 전자 총 8개(옥텟 완성) = 결합 3쌍(6개) + lone pair(2개)

**H⁺ (양성자, 전자 0개)**

```
   H⁺
```
- 전자가 하나도 없는 상태. 그릴 점이 없음 = 빈 오비탈만 존재

**NH<sub>4</sub>⁺ (배위결합 후)**

```
        H
        |
   H — N — H⁺
        |
        H
```
- NH<sub>3</sub>의 lone pair(:)가 그대로 내려와서 H⁺와의 새 결합(N-H)이 됨 → lone pair 자리에 있던 점 2개가 결합선 하나로 바뀜
- 결과: N-H 결합 4개, N에 lone pair 없음 (전자 다 결합에 씀)
- 4개의 N-H 결합은 만들어진 과정(3개는 원래 공유결합, 1개는 배위결합)만 다르고, 완성된 후에는 길이·세기 전부 동일 → 그림상 구별 불가능

**전하가 어디 찍히는지**
- N: 원래 5개 전자 중 4개만 자기 몫(결합 4개 × 1/2씩) → 형식전하 +1
- H 4개: 각각 정상 몫 1개씩 → 형식전하 0
- 전체 이온(NH<sub>4</sub>⁺) 전하 = +1 (N 위치에 표시하지만 실제로는 이온 전체에 걸쳐 있음)

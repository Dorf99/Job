### 혼재 기준 = 서로 다른 유별의 위험물을 같은 차량/용기에 함께 실어도 되는지를 정한 규칙

전체 매트릭스
1류  2류  3류  4류  5류  6류
1류   -    X    X    X    X    O
2류   X    -    X    O    O    X
3류   X    X    -    O    X    X
4류   X    O    O    -    O    X
5류   X    O    X    O    -    X
6류   O    X    X    X    X    -
**암기법: "423 524 61"**
4류는 2,3류와 혼재 가능
5류는 2,4류와 혼재 가능
6류는 1류와 혼재 가능

**왜 이 조합들이 허용되는지 (지금까지 배운 성질로 설명됨)**

| 조합          | 이유                                                          |
| ----------- | ----------------------------------------------------------- |
| **1류 ↔ 6류** | 둘 다 "산화성"(고체/액체 차이일 뿐, 같은 성질끼리라 상대적으로 덜 충돌)                 |
| **2류 ↔ 4류** | 둘 다 가연성(고체/액체), 서로 불을 더 키우진 않음                              |
| **2류 ↔ 5류** | 가연성고체 + 자기반응성물질, 상대적으로 안정 조합                                |
| **3류 ↔ 4류** | 자연발화성물질 + 인화성액체, 지정수량 조건 하에 허용                              |
| **4류 ↔ 5류** | 인화성액체 + 자기반응성물질 (5류 다이너마이트류가 4류 용제 쓰는 경우 많아서 실무상 자주 같이 다뤄짐) |
*혼재 불가 = 절대 같은 공간 금지"가 아니라 "지정수량의 1/10 이하면 예외*

|**냉각소화**|온도를 발화점 아래로 낮춤|**열(점화원)**|물 뿌리기 — 물의 기화열로 열을 뺏음|

|**제거소화**|가연물 자체를 없앰|**가연물**|가스밸브 잠그기, 산불 시 나무 미리 벌목|

6류(주수) → 냉각소화

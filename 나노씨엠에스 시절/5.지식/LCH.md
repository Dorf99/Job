# LCH

## 정의

LCH는 CIELAB 색공간을 사람이 이해하기 쉽게 표현한 색 좌표계이다.

- L = Lightness(명도)
- C = Chroma(채도)
- H = Hue Angle(색상각)

CIELAB의 a*, b* 값을 극좌표 형태로 변환하여 표현한다.

---

## 구성 요소

### L (Lightness)

명도

- 0 = 검정
- 100 = 흰색

CIELAB의 L*와 동일하다.

---

### C (Chroma)

채도


- 값이 클수록 선명한 색
- 값이 작을수록 탁한 색

---

### H (Hue Angle)

색상을 각도로 표현한다.

| 각도       | 색상         |
| -------- | ---------- |
| 0°       | 빨강(Red)    |
| 90°      | 노랑(Yellow) |
| 180°     | 초록(Green)  |
| 270°     | 파랑(Blue)   |
| 360°(0°) | 다시 빨강      |

---

## 장점

- 색상(Hue)과 채도(Chroma)를 직관적으로 해석할 수 있다.
- 색 변화 방향을 이해하기 쉽다.

---

## 회사 업무에서 해석

### L 감소
→ 시료가 더 어두워짐

### L 증가
→ 시료가 더 밝아짐

### C 감소
→ 색이 탁해짐

### C 증가
→ 색이 선명해짐

### H 감소
→ 색상이 시계방향 기준으로 낮은 각도로 이동

### H 증가
→ 색상이 높은 각도로 이동

※ h° 값은 현재 위치에 따라 해석이 달라지므로 단순히 증가·감소만으로 색상을 판단하지 않는다.

예시)

332° → 327°

→ Red 계열 방향으로 이동
→ 붉은 기가 약간 증가한 것으로 해석 가능

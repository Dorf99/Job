# AMMK RF품질관리팀 경력기술서

> [!abstract] 최종 정리 기준 · 2026-11-05
> 실제 주된 일은 **제품 품질평가용 시편의 반복 전처리(분류·테이프 부착 → 동박 에칭 → 에칭 후 재절단·정리) 및 에칭 장비 운용**이다. **원판의 최초 재단은 다른 작업자가 해 준다.** 품질팀 담당자가 후속 분석기기로 평가하며, **내열성 Solder Float Test는 시간 여유가 있을 때 일부 수행하는 보조 시험**이다. 11월 5일에는 **신형 박리강도 시험기로 PRE-TEST용 '핀' 시편을 직접 시험하고 측정값을 기록**했다. **제품용 시편 박리시험은 수행하지 않았다.** 이 최신 설명을 이전 기록보다 우선한다.
>

## 2. 담당업무 (실제 수행 중심)

### 2-1. 품질평가용 시편 준비 및 테이프 부착 — 주 업무

- 타 작업자가 **규격에 따라 미리 재단해 준 동박 부착 소재/시편을 인수**해 제품·규격별로 구분.
- 크기와 두께가 제각각인 **다양한 시편을 하루 동안 반복·다량 취급**하며 시험 준비.
- 사진과 같이 길고 평평한 **판형 받침/지지대(현장 정식 명칭 미확인)**에 각 시편을 **하나씩 테이프로 부착·배열**하여 에칭 투입 준비.
- P(5단), R(8단), E(10단), C2 등 제품별 차이를 숙지하고 작업 순서와 투입 시 주의사항에 반영.
- **제품 품질평가용 시편 우선**, 시험(Test)용 시편 후순위로 처리하는 현장 우선순위에 따라 작업.

> [!important] 업무 범위 정정
> **최초 제품 동판의 규격별 재단은 본인 담당이 아니다.** 기존 기록의 '동판 절단·테이프 부착 후 에칭'이라는 표현은 **타 작업자가 재단한 시편을 받아 부착하는 업무**와 **에칭 후 시편을 다시 자르는 업무**를 혼동한 것이다. 이 최종본에서는 이를 분리했다.

### 2-2. 동박 에칭 장비 운용 — 주 업무

- **TAESUNG TSG-HALF-100** 에칭 장비를 활용한 시험용 시편의 동박 제거 작업 반복 수행.
- 현장 교육에 따라 **기본 가동·정지, HMI 자동모드/설비 상태 확인, 컨베이어 투입·이송** 작업 경험.
- 장비의 공정 흐름인 **에칭 → 수세 → 액절 → 열풍건조**를 거친 시편 회수·처리.
- 제품 두께 및 이송 상태에 따라 걸림·간섭 가능성에 주의하며 작업(C2는 두꺼워 간격 확보 필요).
- 장비 알람·이상 발생 시 담당자에게 즉시 보고하는 지침 숙지. 관련 기록표 및 약품·설비 점검업무 보조.

### 2-3. 에칭 후 시편 재가공·정리 — 주 업무

- 에칭 후 나온 시편을 **하나씩 다시 절단·다듬어 분리**, 시험 목적과 시편별로 분류·정리.
- 필요 시 에탄올을 묻힌 와이퍼로 시편 표면을 닦는 세척 작업 수행.
- 전처리가 끝난 시편을 정리해 **RF품질관리팀의 후속 분석·물성시험에 사용할 수 있도록 준비**.
- 다량의 시편을 규격·식별 표기와 혼동하지 않도록 취급·정리하는 반복 작업 경험.

### 2-4. 에칭 후 표면 이물 확인 — 수행 경험

- 에칭 후 남은 기판성 시편의 표면에서 **작은 점 형태의 이물·이상 의심 부위** 확인.
- 의심 부위에 **위치 표시·체크 및 숫자 기재**하는 검사 지원 업무 수행.
- 공식 합격/불합격 최종 판정과 시험 성적서 작성은 **담당했다고 확인되지 않음**.

### 2-5. 내열성 시험(Solder Float Test, SFT) — 간헐적 보조 업무

- 시편 준비 및 **Solder Pot #1**을 활용한 고온 내열성 시험을 **시간 여유가 있을 때 일부 수행**.
- 직접 경험한 시험에서는 **약 10개 시편**을 대상으로 **약 3분간** 용융 솔더에 노출되는 과정을 타이머로 확인하고, **표면 부풀음/기포 형상** 유무를 관찰.
- 현장 작업지침서상의 정식 시험명은 **내열성 Test(SFT, Floating Test)**이며, 기준 조건은 **288±5°C / 3분**.
- 관찰 대상 결함: **Blister(부풀음), Delamination(층간 박리), Measling(내부 흰 반점)** 등.
- 일상 주업무가 아니라 **보조적으로 경험한 내열성 품질시험**으로 표기. 정식 합부 판정·시험 데이터 관리·불합격 후 재시험을 독립 수행했다고 주장하지 않음.

### 2-6. 핀 시편 박리강도 시험 — PRE-TEST 직접 수행 (2026.11.05)
- 2026.11.03 시험 장비 **신형·구형 총 2대**의 구분과 시험 방법을 배움.
- 2026.11.05 작고 긴 **'핀(Pin)' 시편**을 이용한 **박리강도 시험**을 **신형 시험기로 직접 수행**.
- 대상은 **PRE-TEST(사전 시험)용 시편**이며, **제품용 시편 시험은 수행하지 않음**.
- 시험 결과로 나온 **측정 데이터를 직접 기록**하는 업무 수행. 기록 양식과 데이터 저장·관리 범위는 아직 확인되지 않았으므로 '측정 결과 기록'으로 표현.
- 이전에 들은 '측정값 4 미만 시 보고' 지시는 보존하되, 단위·제품별 공식 판정 기준 미확인. **최종 합격/불합격 판정, 분석 데이터 관리, 정식 성적서 발행은 수행 경력으로 기재하지 않음**.
- 신형·구형 장비의 **제조사·모델명 및 시험 각도·속도·단위**는 추후 확인.

### 2-7. 설비·자재 관리 및 작업환경 정리 — 지원업무

- 아침의 **pH 시험지(색 변화형) 점검**·액량 확인, 에칭액 관련 용기 준비 및 보충 과정 **동행·보조**. 시험지를 찢어 액체에 담가 색을 확인하고, 이상한 색 변화가 나타나면 담당자에게 보고하도록 배움(측정 대상과 정상 색 기준 미확인).
- 제품 동판 수령 지원, 종이 포장재와 동판 스크랩의 분리·정리.
- 에칭액 관련 관리 기록표와 일별 설비 알람 횟수 기록표 확인.
- 근무 종료 시 분석실 청소 및 정리정돈 수행.

## 3. 직무 경험 요약 — 채용사이트 복사본

AMMK RF품질관리팀에서 **제품 품질평가용 시편 전처리 및 동박 에칭 장비 운용** 업무를 수행하고 있습니다. 규격별로 사전 재단된 다양한 크기·두께의 시편을 인수하여 판형 지지대에 개별 테이프 부착한 뒤, **TAESUNG TSG-HALF-100** 에칭 장비로 동박 제거·수세·건조 공정을 진행했습니다. 에칭 후에는 시편을 다시 분리·절단·정리하여 품질팀의 후속 분석 및 특성평가에 사용할 수 있도록 준비했습니다. 에칭 후 표면 이물 의심 부위의 표시·기록 업무를 수행했으며, **Solder Float Test(SFT) 내열성 시험**을 보조적으로 경험했습니다. 또한 **신형 박리강도 시험기를 이용해 PRE-TEST용 핀 시편을 직접 측정하고 결과를 기록**했습니다.

## 6. 실제 작업 흐름과 업무량

### 6-1. 일상적인 주 업무의 실제 흐름

1. 제품 품질평가용 동박 부착 소재/시편을 인수한다. **규격에 맞게 처음 잘라 주는 사람은 따로 있다.**
2. 크기·두께·제품코드가 서로 다른 시편을 구분한다.
3. 사진 속 **긴 흰색 판형 받침(정식 명칭을 잊어버림)**에 시편을 한 장씩 붙인다. 길게 배열된 여러 시편이 테이프에 고정되어 있다.
4. 시편을 에칭 라인에 넣고 구리층을 제거한다. 장비는 수세·액절·열풍건조 공정까지 포함한다.
5. 에칭된 시편을 회수한다. 필요한 경우 에탄올 와이퍼로 표면을 문질러 닦는다.
6. **에칭 후 시편을 다시 하나하나 자르고 다듬어**, 제품·시험 목적별로 구분해 놓는다.
7. 준비된 시편은 품질팀 담당자들이 별도 분석·측정 장비로 특성을 평가한다.
8. 시간이 남으면 SFT 내열성 시험 같은 일부 검사를 맡는 경우가 있다.

**작업량 기록:** 여러 규격을 대상으로 위 과정을 **하루에 매우 많이 반복**함. 정확한 일일 매수, 전처리 처리량, 시험 의뢰 건수는 미집계이므로 수치로 만들지 않는다.

**정식 명칭 미확인:** 긴 흰 판·종이판처럼 보이는 **시편 부착용 받침**의 현장 명칭을 사용자가 잊음. 사진만으로 '지그', '리드보드', '캐리어' 등으로 단정하지 않는다.

### 6-2. 아침 점검·자재 준비·기타 보조 작업

- 출근 후 출석 기재 및 작업 전 체조·운동.
- 담당자를 따라가 **pH 점검**과 **액체 잔량(L)** 확인 과정을 봄. **2026.11.04 pH 시험지를 필요한 만큼 찢어 액체에 담가 색 변화를 확인하고 이상한 색이면 보고하는 방식**을 확인함. 별도 pH 전자 측정기 사용 경험으로 기재하지 않음. 현장 지침서에 스크러버 탱크액 pH 관리가 있지만 **아침 측정 대상과 정확히 같은지, 정상 색상·pH 범위는 확인되지 않음**.
- 창고의 대차 이용. 에칭액 관련 용기를 **2통씩 준비**하도록 배움.
- 약액 보충할 때 동행해 **뚜껑 닦기**, 사용 후 용기를 대차로 창고 쪽 이동. '버리기'가 폐기인지 반납인지 미확인.
- 아침에 제품 동판 수령을 위해 같이 이동하고, 바닥에 놓는 종이·포장재 및 동판 스크랩을 정리.
- 동판 스크랩은 **크기에 맞춰 구분하여 폐기**.
- 관리자는 작업 중 특이사항이 있으면 **즉시 보고**하라고 교육함.
- 근무 종료 시 **분석실 청소**.

### 7-5. Copper Foil Etching 작업지침서에서 확인한 공정

## 9. 품질시험·검사 경험 상세

### 9-1. Solder Float Test(SFT) — 정식 시험명 확인

**출처:** AMMK 특성검사 **작업지침서 「내열성 Test(SFT)」, 문서번호 TCG-AQ-51, 개정일 2025.08.08** 및 장비·표지 사진.

| 항목 | 사진에서 확인한 정보 | 실제 사용자 업무 경계 |
| --- | --- | --- |
| 시험명 | **내열성 Test (SFT)**, **Floating Test** | 약 3분 표면 부풀음 관찰 시험을 실제 수행 |
| 시험장비 | **Solder Pot #1**, 설비관리번호 **TCD-AB-11**, 장비 표시 모델 **POT-300HD** | 사용 현장·관련 시험 확인 |
| 온도 | **288±5°C** | 사용자 최초 기억은 약 285°C; 정식 지침서로 정정 |
| 시간 | **3분** | 타이머를 켜고 시간 확인하는 일을 경험 |
| 직접 다룬 시편 | 당시 **10개**라고 설명 | **최초 재단은 평소 다른 사람이 수행**. SFT의 10개 절단을 본인이 했는지는 최신 진술과 차이가 있어 최종 확인 필요 |
| 확인 결함 | Measling / Delamination / Blister / 기타 외형 변화 | 기포·표면 부풀음 관찰 경험 |
| 검사 결과 | 개인에게 구체적 수치·합불 결과 없음 | 최종 판정·성적서 관리 주체라고 주장하지 않음 |

**작업지침서 내 상세 절차·기준(직접 담당 여부와 별개):**
- 가열된 Solder Pot을 사용하며 지침서에 **1시간 예열 후 사용**이라고 되어 있음.
- Floating Test: 지침서에 **10초 경과 후 이상이 없는 경우 3분까지 진행**하는 절차가 적혀 있음.
- 사용 전 온도 **좌·중·우 3point 측정 및 기록** 지시가 있음. **사용자가 직접 측정했다고 확인된 것은 아님**.
- 일반 검사기준: **Measling, Delamination, Blister 및 기타 외형 변화가 없을 것**.
- 불합격 시 담당자 보고·Aging 후 재검증 등의 절차가 있으나 **사용자 직접 수행 업무는 아님**.
- 제품별 기준 차이가 적혀 있음(예: CER 10초 이상, 일부 RF 제품 60초 이상). 모든 제품에 무조건 같은 시간을 적용하는 것이 아님.
- 시편 표면이 부풀어 오르는 것은 **Blistering**으로 해석 가능하나, 특정 사진 없이 실제 발생 여부는 미확정.

**비교용으로 문서에 나오는 별도 시험 — 본인 수행 경력에서 제외:**
- **Solder Dipping Test(SDT)**: 문서상 **288±5°C에서 10초씩 5회 반복**(참고시험), 시편 준비 규격에 **2×2 inch 이상** 문구 있음. **현재 직접 수행했다는 진술 없음**.

### 9-2. '핀(Pin)' 시편 박리강도 시험 — 2026.11.05 신형 장비 직접 운용

**기존 관찰 단계에서 직접 시험 단계로 업데이트**
- 10월 하순: 세로로 긴 '핀' 시편에 **3 mm 폭 테이프**를 붙이고 에칭한 후 시험기에 걸어 당기는 과정을 관찰. 구두로 **표시값 4 미만 시 담당자 보고** 지시를 들음(단위·공식 시험규격 미확인).
- **2026.11.03:** 박리강도 시험을 배우기 시작함. 시험 장비가 **신형·구형 총 2대**임을 확인함. 구형 장비 관련 접근정보는 보안상 문서에 남기지 않음.
- **2026.11.05:** 작고 긴 에칭된 **핀 시편으로 신형 시험기를 직접 사용해 박리강도 시험을 수행**, **측정 데이터를 직접 기록**함.
- **시험한 시편:** **PRE-TEST용**. **정규 제품용 시편은 시험하지 않았음**.
- **직접 수행 범위:** 시험기 조작을 통한 PRE-TEST 측정과 결과 기록. **정식 검사 성적서 발행, 전체 시험 데이터 관리, 합격/불합격 최종 판정**은 수행한 것으로 적지 않음.
- **추가 확인:** 신형 장비 모델명, 시험각도·이송속도, 측정 단위 및 4 미만 판정 기준, 측정값 기록 매체(시편·종이·전산 등).
- '인장강도'와 혼용해 표현했던 과거 기록을 **현장 호칭 '핀 박리강도 시험'**으로 정정. 구체적인 시험 표준은 미확인.

### 9-3. 에칭 후 이물검사

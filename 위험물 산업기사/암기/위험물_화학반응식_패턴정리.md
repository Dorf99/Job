# 위험물 화학반응식 - 패턴 정리

40개 개별 반응식이 아니라 **패턴 5개 + 예외 5개**로 압축

---

## 패턴① 금수성 금속 + 물 → 수산화물 + H2↑

전부 똑같은 틀. 물질만 바뀜.

- **1가 금속** (K, Na): `2M + 2H2O → 2MOH + H2↑`
- **2가 금속** (Ca, Mg, Zn): `M + 2H2O → M(OH)2 + H2↑`
- **Al(3가, 예외 계수)**: `2Al + 6H2O → 2Al(OH)3 + 3H2↑`

| 금속 | 반응성 | 비고 |
|---|---|---|
| K | 매우 격렬 | 92.8kcal 발열 |
| Na | 격렬 | 92.8kcal 발열 |
| Ca | 중간 | 소석회(Ca(OH)2) 생성 |
| Mg | 느림(찬물) | 뜨거운물/수증기와는 격렬 |
| Al | 산화막 있어서 원래 느림 | 산·알칼리 모두와 반응 (양쪽성) |
| Zn | 느림 | 산·알칼리 모두와 반응 (양쪽성) |

→ **암기할 건 딱 하나: "반응성 순서 K>Na>Ca>Mg>Al>Zn" + "Al,Zn은 양쪽성(산·알칼리 둘 다 반응)"**

---

## 패턴② 무기과산화물 4형제 반응

K2O2, Na2O2, BaO2, MgO2, CaO2 — **5개 물질이 아니라 반응틀 4개**

| 반응 상대 | 결과 | 기억 포인트 |
|---|---|---|
| 그냥 분해 | 산화물 + O2↑ | 열분해 |
| **+ H2O** | 수산화물 + **O2↑** + 발열 | 물 만나면 → 산소 발생 → **주수금지** |
| + HCl / H2SO4 | 염(chloride/sulfate) + **H2O2** | 산 만나면 → 과산화수소 생성 |
| + CO2 | 탄산염 + O2↑ | 이산화탄소소화기 사용 금지 이유 |

→ **암기 문장 1개**: "과산화물은 물 만나면 산소, 산 만나면 과산화수소를 낸다"

---

## 패턴③ 금속화합물 + 물 → 특정 가스 (3쌍만 매칭)

| 물질 | + 물 → | 발생 가스 |
|---|---|---|
| 탄화칼슘 CaC2 | Ca(OH)2 + | **아세틸렌 C2H2** |
| 탄화알루미늄 Al4C3 | Al(OH)3 + | **메탄 CH4** |
| 인화칼슘 Ca3P2 | Ca(OH)2 + | **포스핀 PH3** |
| 수소화나트륨 NaH | NaOH + | **수소 H2** |

→ **암기: "탄화칼슘=아세틸렌, 탄화알루미늄=메탄, 인화칼슘=포스핀"** (이 3개가 시험 최다빈출)

---

## 패턴④ 1차 알코올의 산화 단계 (순서만 기억)

```
알코올  →(산화)→  알데하이드  →(산화)→  카르복실산
메탄올(CH3OH)  →  폼알데하이드(HCHO)  →  폼산(HCOOH)
에탄올(C2H5OH)  →  아세트알데하이드(CH3CHO)  →  아세트산(CH3COOH)
```

→ **암기: "알코올 산화 2단계 거치면 산이 된다" 구조만, 물질명은 세트로 딸려옴**

---

## 패턴⑤ 유기물 연소 = CO2 + H2O (계수는 안 외워도 됨)

벤젠, 클로로벤젠, 이황화탄소, 아세트알데히드 등 → 시험에서 계수는 산소 균형 맞추기로 그 자리에서 풀면 됨. **패턴이 아니라 스킬**이라 암기 대상 제외.

단, 이황화탄소(CS2)만 예외 생성물 주의:
- `CS2 + 3O2 → CO2 + 2SO2↑` (연소, 아황산가스)
- `CS2 + 2H2O → CO2 + 2H2S↑` (150℃, **물과도 반응** — 특이 케이스)

## 진짜 예외 (패턴 안 통함, 개별 암기 필요)

### 1. 질산암모늄 (NH4NO3) — 온도별로 다른 생성물
- 260℃: `NH4NO3 → N2O + 2H2O`
- 폭발 시: `2NH4NO3 → 2N2 + 4H2O + O2↑`

### 2. TNT / TNP(피크르산) 분해식 — 계수 복잡, 통암기
- TNT: `2C6H2CH3(NO2)3 → 2C + 3N2↑ + 5H2↑ + 12CO↑`
- TNP: `2C6H2(NO2)3OH → 2C + 3N2↑ + 5H2↑ + 4CO2↑ + 6CO↑`

### 3. 은거울 반응 (아세트알데히드 + 암모니아성 질산은)
`CH3CHO + 2Ag(NH3)2OH → CH3COOH + 2Ag + 4NH3 + H2O`
→ 알데히드 검출 반응이라는 것만 기억

### 4. 분말소화약제 열분해 — 온도 2단계로 다른 생성물
| 물질 | 1차 | 2차 |
|---|---|---|
| 탄산수소나트륨(NaHCO3) | 270℃ → Na2CO3 | 850℃ → Na2O |
| 탄산수소칼륨(KHCO3) | 190℃ → K2CO3 | 590℃ → K2O |
| 인산암모늄(NH4H2PO4) | 190℃ → H3PO4 | 215℃→피로인산 → 300℃→메타인산 |

### 5. 과산화수소 분해 — 정촉매 기억
`2H2O2 → 2H2O + O2` (정촉매: MnO2, KI)

| **구분**                  | **이유**                  | **대표 예시**                                                                 |
| ----------------------- | ----------------------- | ------------------------------------------------------------------------- |
| **1. 최고 산화수(완전 연소) 물질** | 이미 산소와 최대로 결합해서 더 타지 않음 | **$\text{CO}_2$ (이산화탄소)**, $\text{H}_2\text{O}$ (물), $\text{SO}_3$ (삼산화황) |
| **2. 비활성 기체 (18족 원소)**  | 반응성이 전혀 없어서 화학 반응을 안 함  | 헬륨($\text{He}$), 네온($\text{Ne}$), 아르곤($\text{Ar}$)                        |
| **3. 이미 흡열/자체 안정 물질**   | 질소처럼 결합력이 너무 강함         | 질소($\text{N}_2$)                                                          |

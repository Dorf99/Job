# 위험물 화학반응식 - 패턴 정리

40개 개별 반응식이 아니라 **패턴 5개 + 예외 5개**로 압축

---

## 패턴① 금수성 금속 + 물 → 수산화물 + H<sub>2</sub>↑

전부 똑같은 틀. 물질만 바뀜.

- **1가 금속** (K, Na): `2M + 2H₂O → 2MOH + H₂↑`
- **2가 금속** (Ca, Mg, Zn): `M + 2H₂O → M(OH)₂ + H₂↑`
- **Al(3가, 예외 계수)**: `2Al + 6H₂O → 2Al(OH)₃ + 3H₂↑`

| 금속 | 반응성 | 비고 |
|---|---|---|
| K | 매우 격렬 | 92.8kcal 발열 |
| Na | 격렬 | 92.8kcal 발열 |
| Ca | 중간 | 소석회(Ca(OH)<sub>2</sub>) 생성 |
| Mg | 느림(찬물) | 뜨거운물/수증기와는 격렬 |
| Al | 산화막 있어서 원래 느림 | 산·알칼리 모두와 반응 (양쪽성) |
| Zn | 느림 | 산·알칼리 모두와 반응 (양쪽성) |

→ **암기할 건 딱 하나: "반응성 순서 K>Na>Ca>Mg>Al>Zn" + "Al,Zn은 양쪽성(산·알칼리 둘 다 반응)"**

---

## 패턴② 무기과산화물 4형제 반응

K<sub>2</sub>O<sub>2</sub>, Na<sub>2</sub>O<sub>2</sub>, BaO<sub>2</sub>, MgO<sub>2</sub>, CaO<sub>2</sub> — **5개 물질이 아니라 반응틀 4개**

| 반응 상대 | 결과 | 기억 포인트 |
|---|---|---|
| 그냥 분해 | 산화물 + O<sub>2</sub>↑ | 열분해 |
| **+ H<sub>2</sub>O** | 수산화물 + **O<sub>2</sub>↑** + 발열 | 물 만나면 → 산소 발생 → **주수금지** |
| + HCl / H<sub>2</sub>SO<sub>4</sub> | 염(chloride/sulfate) + **H<sub>2</sub>O<sub>2</sub>** | 산 만나면 → 과산화수소 생성 |
| + CO<sub>2</sub> | 탄산염 + O<sub>2</sub>↑ | 이산화탄소소화기 사용 금지 이유 |

→ **암기 문장 1개**: "과산화물은 물 만나면 산소, 산 만나면 과산화수소를 낸다"

---

## 패턴③ 금속화합물 + 물 → 특정 가스 (3쌍만 매칭)

| 물질 | + 물 → | 발생 가스 |
|---|---|---|
| 탄화칼슘 CaC<sub>2</sub> | Ca(OH)<sub>2</sub> + | **아세틸렌 C<sub>2</sub>H<sub>2</sub>** |
| 탄화알루미늄 Al<sub>4</sub>C<sub>3</sub> | Al(OH)<sub>3</sub> + | **메탄 CH<sub>4</sub>** |
| 인화칼슘 Ca<sub>3</sub>P<sub>2</sub> | Ca(OH)<sub>2</sub> + | **포스핀 PH<sub>3</sub>** |
| 수소화나트륨 NaH | NaOH + | **수소 H<sub>2</sub>** |

→ **암기: "탄화칼슘=아세틸렌, 탄화알루미늄=메탄, 인화칼슘=포스핀"** (이 3개가 시험 최다빈출)

## 패턴④ 1차 알코올의 산화 단계 (순서만 기억)

```
알코올  →(산화)→  알데하이드  →(산화)→  카르복실산
메탄올(CH₃OH)  →  폼알데하이드(HCHO)  →  폼산(HCOOH)
에탄올(C₂H₅OH)  →  아세트알데하이드(CH₃CHO)  →  아세트산(CH₃COOH)
```

→ **암기: "알코올 산화 2단계 거치면 산이 된다" 구조만, 물질명은 세트로 딸려옴**

---

## 패턴⑤ 유기물 연소 = CO<sub>2</sub> + H<sub>2</sub>O (계수는 안 외워도 됨)

벤젠, 클로로벤젠, 이황화탄소, 아세트알데히드 등 → 시험에서 계수는 산소 균형 맞추기로 그 자리에서 풀면 됨. **패턴이 아니라 스킬**이라 암기 대상 제외.

단, 이황화탄소(CS<sub>2</sub>)만 예외 생성물 주의:
- `CS₂ + 3O₂ → CO₂ + 2SO₂↑` (연소, 아황산가스)
- `CS₂ + 2H₂O → CO₂ + 2H₂S↑` (150℃, **물과도 반응** — 특이 케이스)

## 진짜 예외 (패턴 안 통함, 개별 암기 필요)

### 1. 질산암모늄 (NH<sub>4</sub>NO<sub>3</sub>) — 온도별로 다른 생성물
- 260℃: `NH₄NO₃ → N₂O + 2H₂O`
- 폭발 시: `2NH₄NO₃ → 2N₂ + 4H₂O + O₂↑`

### 2. TNT / TNP(피크르산) 분해식 — 계수 복잡, 통암기
- TNT: `2C₆H₂CH₃(NO₂)₃ → 2C + 3N₂↑ + 5H₂↑ + 12CO↑`
- TNP: `2C₆H₂(NO₂)₃OH → 2C + 3N₂↑ + 5H₂↑ + 4CO₂↑ + 6CO↑`

### 3. 은거울 반응 (아세트알데히드 + 암모니아성 질산은)
`CH₃CHO + 2Ag(NH₃)₂OH → CH₃COOH + 2Ag + 4NH₃ + H₂O`
→ 알데히드 검출 반응이라는 것만 기억

### 4. 분말소화약제 열분해 — 온도 2단계로 다른 생성물
| 물질 | 1차 | 2차 |
|---|---|---|
| 탄산수소나트륨(NaHCO<sub>3</sub>) | 270℃ → Na<sub>2</sub>CO<sub>3</sub> | 850℃ → Na<sub>2</sub>O |
| 탄산수소칼륨(KHCO<sub>3</sub>) | 190℃ → K<sub>2</sub>CO<sub>3</sub> | 590℃ → K<sub>2</sub>O |
| 인산암모늄(NH<sub>4</sub>H<sub>2</sub>PO<sub>4</sub>) | 190℃ → H<sub>3</sub>PO<sub>4</sub> | 215℃→피로인산 → 300℃→메타인산 |

### 5. 과산화수소 분해 — 정촉매 기억
`2H₂O₂ → 2H₂O + O₂` (정촉매: MnO<sub>2</sub>, KI)

**Br은 브로민(Bromine, 브롬)**이에요.

- 주기율표 17족(할로젠족), 원자번호 35번
- Cl(염소) 바로 아래 칸에 있는 원소라 **화학적 성질이 Cl이랑 거의 똑같아요** (같은 족이니까)
- 상온에서 **액체** 상태인 게 특이점 (할로젠 중 유일하게 상온 액체 — Cl은 기체, I는 고체)

**Cl이랑 똑같은 패턴을 그대로 따라감**

지금까지 배운 Cl 산소산 계열이 Br한테도 그대로 적용돼요:

|Cl 계열|Br 계열 (대응)|
|---|---|
|ClO⁻ (차아염소산)|BrO⁻ (차아브로민산)|
|ClO2⁻ (아염소산)|BrO2⁻ (아브로민산)|
|**ClO3⁻ (염소산, 기본형)**|**BrO3⁻ (브로민산, 기본형)**|
|ClO4⁻ (과염소산)|BrO4⁻ (과브로민산)|

위험물 1류 표에 나온 "브로민산염류(BrO3⁻)"가 바로 이 기본형이에요 — Cl의 염소산(ClO3⁻)이랑 완전히 같은 논리로 만들어진 이름이고, **지정수량도 염소산염류(50kg)보다 한 단계 낮은 300kg**인 이유는 상대적으로 위험성이 좀 덜하다고 분류됐기 때문이에요.

**정리**: Br은 Cl의 "한 주기 아래 사촌"이라고 보시면 되고, 명명법 규칙(차아-아-기본-과)도 그대로 복사해서 쓰면 돼요.

## 과산화물 (O2²⁻)

**산소 2개가 O-O 공유결합으로 붙어서 만든 이온**. 일반 산화물(O²⁻, 산소 1개 독립)과는 다른 계열.

- 산소 하나당 형식전하: 6(원래) − 6(lone pair) − 1(결합전자 절반) = **-1**
- 산소 2개 × (-1) = 전체 이온 전하 **-2**
- 필요한 외부 전자는 2개뿐 → 1족 금속 2개(각 1개씩, Na2O2) 또는 2족 금속 1개(2개 한번에, MgO2) 둘 다 결합 가능

**루이스 구조**: `[ :Ö—Ö: ]²⁻`

**위험성**: O-O 결합이 약해서 잘 끊어짐
- 물과 만나면 → 산소(O2) 가스 발생 → 주수금지
- 산과 만나면 → 과산화수소(H2O2) 생성

**전하가 정해지는 방식**: 단순 결합(뭉치기만 함, 물 안 빠짐) → 각자 전하 그대로 더함

## 다이크로뮴산염류 (Cr2O7²⁻)

**"다이-"는 산화수 접두어(차아/아/과)가 아니라 원소 개수 접두어** — Cr이 2개 들어있다는 뜻.

**만들어지는 과정 (축합반응, 물이 빠지며 결합)**
```
2 CrO4²⁻ (크로뮴산 이온 2개) + 2H⁺ → Cr2O7²⁻ + H2O
```
크로뮴산 이온(CrO4²⁻) 두 개가 산소 하나를 물(H2O) 형태로 잃으면서 결합된 구조.

**전하가 -2인 이유 (전하보존으로 확인)**
```
좌변: CrO4²⁻(-2) + CrO4²⁻(-2) + H⁺(+1) + H⁺(+1) = -2
우변: Cr2O7²⁻(?) + H2O(0) = -2  →  Cr2O7²⁻ = -2
```
CrO4²⁻ 두 개(-4)에서 H⁺ 두 개(+2)가 상쇄시켜서 -2가 됨. ("-4가 아니라 -2인 이유")

**Cr의 산화수 = +6 (실험적으로 정해진 값, 암기 대상)**
```
CrO4²⁻: Cr + (-2×4) = -2 → Cr = +6
Cr2O7²⁻: 2×Cr + (-2×7) = -2 → Cr = +6 (동일)
```

**표에서 확인되는 증거**: (NH4)2Cr2O7 (다이크로뮴산암모늄)만 NH4⁺가 2개 붙음 — 다른 -1가 이온들은 NH4 1개로 충분한데 얘만 2개 필요 = -2가라는 뜻.

**전하가 정해지는 방식**: 축합(원래 이온 2개가 물 잃으며 결합) → 단순 덧셈이 아니라 H⁺의 상쇄까지 계산해야 함

## 나머지 정리 — 전하가 정해지는 3갈래 방식

| 유형 | 대표 예 | 전하가 정해지는 방식 |
|---|---|---|
| ① 단순 산소산 | ClO2⁻, ClO3⁻, ClO4⁻, BrO3⁻, IO3⁻, NO3⁻, MnO4⁻ | 중심원소 하나 + 산소들, 관례상 -1이 되도록 산화수 역산 |
| ② 단순 결합(뭉치기만) | O2²⁻ (과산화물) | 이온 두 개가 그냥 붙음, 각자 전하 그대로 더함 |
| ③ 축합(물 빠지며 결합) | Cr2O7²⁻ (다이크로뮴산) | 원래 이온 2개가 물(H2O) 잃으며 결합 → H⁺가 전하 일부 상쇄 |

**시험용 암기표 (이유 유도 안 하고 그냥 외우는 값)**

```
ClO2⁻, ClO3⁻, ClO4⁻, BrO3⁻, IO3⁻, NO3⁻, MnO4⁻  → 전부 -1가
O2²⁻ (과산화물)                                  → -2가
Cr2O7²⁻ (다이크로뮴산)                            → -2가
```

이 값 자체를 표로 외우고 화학식 만들 때(교차규칙) 바로 꺼내 쓰는 게 실전적 — 매번 축합반응식이나 루이스구조로 유도할 필요는 없음.

### 유기금속화합물

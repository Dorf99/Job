PV = nRT

| 기호  | 뜻              | 단위    |
| --- | -------------- | ----- |
| P   | 압력 (Pressure)  | atm   |
| V   | 부피/체적 (Volume) | L     |
| n   | 몰수 (mole)      | mol   |
| R   | 기체상수 (고정값)     | 0.082 |
| T   | 절대온도 (Kelvin)  | K     |

**R = 0.082 (단위 atm·L/mol·K)
섭씨 → 켈빈 변환 =  +273
R = PV/nT = (1atm × 22.4L) / (1mol × 273K) ≈ 0.082

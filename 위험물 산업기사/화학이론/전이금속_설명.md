# 전이금속 설명

## 정의

주기율표 **3족~12족**에 속하는 금속. 영어로 transition metal, **전이금속 = 천이금속**(같은 뜻, "전이금속"이 현재 한국 표준 용어).

d오비탈을 채우는 원소들이라 **d블록**이라고도 부름.

## 왜 주족원소(1,2,13~18족)와 다르게 취급하나

주족원소는 "족 번호 = 최외각 전자수 = 전하" 공식이 그대로 통함 (Na⁺, Mg²⁺, Al³⁺, O²⁻).

전이금속은 **최외각(4s) 전자뿐 아니라 바로 안쪽 d오비탈 전자까지 화학반응에 같이 관여**해서 이 공식이 안 통함. 그래서 "몇 족이니까 몇 가"라고 계산할 수 없고, **하나의 금속이 여러 산화수를 가질 수 있음**.

## 전이금속의 특징

1. **여러 산화수 가능** (가장 중요한 특징)
2. 대부분 최외각(4s)에 전자 2개로 거의 동일 (Cr, Cu 등 일부 예외 있음 → 오비탈 이론정리 파일 참고)
3. 색을 띠는 화합물이 많음 (d전자의 전자전이 때문 — KMnO4의 진보라색, K2Cr2O7 등)
4. 촉매로 많이 쓰임 (MnO2, Pt 등)

## 흔한 산화수 (위험물 표에 나오는 것 위주)

| 금속 | 흔한 산화수 | 위험물 표 예시 |
|---|---|---|
| Fe (철) | +2, +3 | FeCl2(염화제1철), FeCl3(염화제2철) — 반응식 "2Fe+6HCl→2FeCl3+3H2"에서 나온 그 Fe |
| Mn (망간) | +2, +4, +7 | MnO4⁻(+7, 과망가니즈산 이온), MnO2(+4, 과산화수소 분해 촉매) |
| Cr (크로뮴) | +3, +6 | Cr2O7²⁻(+6, 다이크로뮴산 이온) |
| Cu (구리) | +1, +2 | |
| Zn (아연) | +2 (거의 고정) | Zn(BrO3)2 등 — 예외적으로 산화수 하나뿐 |

## 화합물 이름에서 산화수 읽는 법 (실전 스킬)

전이금속 화합물은 이름/화학식에서 **다른 원소의 산화수를 역산**해서 전이금속의 산화수를 알아냄.

**예 1**: FeCl3 (염화제2철)
```
Cl은 -1 (17족 할로젠) × 3개 = -3
전체 중성(0)이어야 하므로 Fe = +3
→ 이름의 "제2철"이 Fe³⁺(3가)라는 뜻
```

**예 2**: MnO4⁻ (과망가니즈산 이온)
```
O는 -2 × 4개 = -8
전체 전하가 -1이어야 하므로: Mn + (-8) = -1 → Mn = +7
```

**예 3**: Cr2O7²⁻ (다이크로뮴산 이온)
```
O는 -2 × 7개 = -14
전체 전하가 -2여야 하므로: 2×Cr + (-14) = -2 → 2×Cr = +12 → Cr = +6
```

## 이름에 붙는 "제1/제2" 표기 규칙

한국 관용명에서 전이금속의 낮은 산화수 = "제1", 높은 산화수 = "제2"로 표기:
- FeCl2 = 염화**제1**철 (Fe²⁺)
- FeCl3 = 염화**제2**철 (Fe³⁺)

## 정리 — 실전 결론

전이금속은 전자배치를 계산해서 산화수를 구하려 하지 말고, **화합물의 화학식이나 이름에서 다른 원소(O, Cl 등)의 정해진 산화수를 기준으로 역산**하는 게 훨씬 빠르고 정확함.

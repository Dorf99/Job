# 양이온 vs 음이온 판별 원리

**족(자릿수) = 전하의 크기 / 금속·비금속 여부 = 전하의 부호**

| | 금속 (전자 잃음 → 양이온) | 비금속 (전자 얻음 → 음이온) |
|---|---|---|
| 1족 | Na⁺, K⁺ (1가 양이온) | — (H는 예외, 상황에 따라 +1/-1) |
| 2족 | Mg²⁺, Ca²⁺, Ba²⁺ (2가 양이온) | — |
| 13족 | Al³⁺ (3가 양이온) | — |
| 16족 | — | O²⁻, S²⁻ (2가 음이온) |
| 17족 | — | Cl⁻, Br⁻, I⁻ (1가 음이온) |

## 핵심 원리

- **몇 족인가** → 전하의 크기(몇 가인지)를 결정
- **금속인가 비금속인가** → 전하의 부호(+/−)를 결정

## 예시: Mg가 왜 양이온인가

- 3주기, 2족 → 크기는 "2가"
- 금속 → 전자를 **잃는** 쪽 → 부호는 "+"
- 결론: **Mg²⁺**

## 예시: O가 왜 음이온인가

- 2주기, 16족 → 크기는 "2가"
- 비금속 → 전자를 **얻는** 쪽 → 부호는 "-"
- 결론: **O²⁻**

## 위험물 표 적용

Mg(ClO<sub>4</sub>)<sub>2</sub> = Mg²⁺(양이온 1개) + ClO<sub>4</sub>⁻(음이온 2개)
→ 전하 합: (+2) + (-1×2) = 0 → 중성 화합물 성립
